# Community Profiling System

A comprehensive system to test community profiling by creating train/test splits, running Girvan-Newman community detection on training data only, and then testing how well unseen games can be assigned to communities using cosine similarity with community feature profiles.

## Overview

This system addresses the question: **"Can we predict which community an unseen game belongs to based on its feature vector and community profiles?"**

### Methodology

1. **Train/Test Split**: Split all games into training and testing sets
2. **Community Detection**: Run Girvan-Newman algorithm only on training games
3. **Community Profiling**: Create average feature vectors for each detected community
4. **Test Assignment**: Assign test games to communities using cosine similarity
5. **Evaluation**: Analyze assignment quality and community coverage

## Detailed Usage

### 1. Running the Experiment

The main wrapper script `run_community_profiling_experiment.sh` handles the entire workflow:

```bash
Usage: ./run_community_profiling_experiment.sh --edges EDGES_FILE [OPTIONS]

Required:
  --edges FILE          Path to edges CSV file (supports .gz)

Optional:
  --features-dir DIR    Directory with feature matrices (default: data/features/games_matrix)
  --test-ratio RATIO    Fraction for testing (default: 0.2)
  --out-dir DIR         Output directory (default: out/community_profiling_experiment)
  --max-communities N   Max communities to detect (default: 10)
  --min-community-size N Minimum community size (default: 5)
  --random-seed N       Random seed (default: 42)
  --python PATH         Python executable (default: python3)
```

### 2. Direct Python Usage

You can also run the system directly with Python:

```python
from pathlib import Path
from community_profiling_system import CommunityProfilingSystem

# Initialize system
system = CommunityProfilingSystem(
    features_dir="data/features/games_matrix",
    edges_file="out/graph_runs/.../edges_top100.csv.gz",
    test_ratio=0.2,
    random_seed=42
)

# Run complete experiment
results = system.run_full_experiment("out/my_experiment")
```

### 3. Step-by-Step Usage

```python
# Create train/test split
train_appids, test_appids = system.create_train_test_split()

# Filter edges to training set only
filtered_edges = system.filter_edges_to_train_set(output_path)

# Run Girvan-Newman on training set
communities = system.run_girvan_newman(filtered_edges, output_dir)

# Create community profiles
profiles = system.create_community_feature_profiles()

# Assign test games to communities
test_assignments = system.assign_test_games_to_communities()

# Evaluate results
evaluation = system.evaluate_assignments(test_assignments, output_dir)
```

## Analysis Tools

### Comprehensive Analysis

The `analyze_profiling_results.py` script provides detailed analysis:

```bash
python analyze_profiling_results.py --results-dir out/community_profiling_experiment_TIMESTAMP
```

This generates:
- **Similarity score distribution**: How well test games matched communities
- **Community assignment balance**: Whether assignments were evenly distributed
- **Train vs test preferences**: Which communities were favored/avoided
- **Comprehensive report**: Text summary of all findings
- **Visualizations**: Histograms and bar plots (optional)

### Key Metrics

The system evaluates:
- **Similarity Scores**: Cosine similarity between test games and assigned communities
- **Coverage**: What percentage of communities received test game assignments
- **Balance**: How evenly test games were distributed across communities
- **Quality Brackets**: High (≥0.8), Medium (0.6-0.8), Low (<0.6) similarity assignments

## Understanding the Results

### Good Results Indicators
- **High mean similarity**: >0.7 suggests good community-game matching
- **High coverage**: >80% of communities receiving assignments shows broad applicability
- **Balanced distribution**: Similar assignment rates to community sizes in training

### Potential Issues
- **Low similarity scores**: May indicate poor community cohesion or inadequate features
- **Low coverage**: Some communities may be too specific or poorly defined
- **Severe imbalance**: Over-assignment to large communities, under-assignment to small ones

Fine-tune Girvan-Newman parameters:

```bash

--min-community-size 15       # Require larger communities
```

### Graph Filtering

The system inherits graph filtering from the original edges file creation. To modify graph structure, regenerate edges with different parameters:

```bash
# Example: Different similarity threshold
./graph_scripts/run_full_cosine_graph_v3.sh \
    --threshold 0.75 \
    --kcore 3
```

## Troubleshooting

### Common Issues

1. **"No edges loaded"**: Check edges file format and path
2. **"Empty graph after filtering"**: Edges file may not contain training games
3. **"Import error for Girvan-Newman"**: Ensure `girvan_newman/scripts/` exists
4. **Low similarity scores**: Consider feature normalization or different similarity metrics

### Performance Tips

- **Large datasets**: Use smaller test ratios (0.1) for faster processing
- **Memory constraints**: Filter to top-k edges per node in original graph construction
- **Speed optimization**: Use `--max-edges` parameter for testing
